# مدیریت پروژه و خدمات فنی

اپلیکیشن offline-first فارسی برای مدیریت پروژه‌ها و خدمات فنی (نصب نور خطی، سیستم صوتی، هوشمند و ...).

## وضعیت فعلی

- Phase 0: آماده‌سازی پروژه (Vite + React + TypeScript + Tailwind + PWA)
- Phase 1: Domain Types + IndexedDB با Dexie + Repository Pattern
- Phase 2: مدیریت مشتریان و پروژه‌ها (کامل)
- Phase 3: پایه فعالیت‌های روزانه + صفحه «فعالیت‌های امروز» (در حال توسعه)

## تکنولوژی‌ها

- Vite + React + TypeScript
- Tailwind CSS
- TanStack Router
- Dexie (IndexedDB)
- vite-plugin-pwa

## اجرا

npm install
npm run dev
