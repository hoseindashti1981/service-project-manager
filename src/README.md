# مدیریت پروژه و خدمات فنی

اپلیکیشن فارسی و آفلاین برای مدیریت مشتریان، پروژه‌ها، خدمات، فعالیت‌ها و اسناد مالی.

## امکانات فعلی

- کاتالوگ خدمات با قیمت پایه و قیمت مستقل در هر پروژه.
- اتصال فعالیت روزانه به خدمت پروژه؛ محاسبه مقدار انجام‌شده، باقی‌مانده و مازاد؛ ویرایش و حذف فعالیت و مرور تاریخ‌های گذشته.
- انتخاب تاریخ شمسی برای مشتری، پروژه، خدمت، قیمت پایه، فعالیت، یادآوری، مصالح، هزینه، کار اضافه و اسناد مالی.
- تاریخ پایان برنامه‌ریزی‌شده و واقعی برای پروژه‌ها؛ تاریخ عملیاتی از زمان ایجاد رکورد جداست. داده‌های قدیمی بدون تاریخ از زمان ثبت قبلی استفاده می‌کنند.
- گردش‌کار پروژه با هفت وضعیت، تاریخ‌های واقعی، ثبت علت توقف/لغو/بازگشایی و تاریخچه تغییرات.
- کارت‌های داشبورد برای پیش‌نویس، برنامه‌ریزی‌شده، در جریان، متوقف و آماده تحویل؛ پروژه‌های فعال قدیمی تا بررسی کاربر در بخش جدا باقی می‌مانند.
- اجرای جدید نیازمند شروع یا ادامه پروژه است؛ ثبت دیرهنگام در روزهای اجرای گذشته با دلیل و اصلاح/حذف فعالیت با سابقه انجام می‌شود. امور مالی مستقل باقی می‌مانند.
- تقویم شمسی با سال کبیسه و روز محلی دستگاه، نمایش شمسی تاریخ اسناد و PDF.

## اجرا و بررسی

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

برای آزمون مرورگر، سرور توسعه باید روی `http://127.0.0.1:5173` روشن باشد. آزمون از Playwright و Microsoft Edge در حالت headless و یک پروفایل موقت مستقل استفاده می‌کند. مسیر ماژول Playwright نصب‌شده را در `SPM_PLAYWRIGHT_PATH` قرار دهید (یا بسته `playwright` را در محیط تست فراهم کنید) و `npm run test:browser` را اجرا کنید. نشانی سرور با `SPM_TEST_URL` قابل تغییر است. تصاویر آزمون در `test-results/` ذخیره می‌شوند؛ داده‌های مرورگر شخصی تغییر نمی‌کنند.

## انتشار

با ارسال به `main`، GitHub Actions آزمون‌ها و Build را اجرا و خروجی را در GitHub Pages منتشر می‌کند. مسیر پایه انتشار `/service-project-manager/` است.
